# ask-dc — 디시인사이드 실시간 여론 및 심층 검색 분석기

디시인사이드 로컬 OpenCLI 어댑터(`opencli dcinside`)를 활용하여 제품 실사용 평가·구매 가이드부터 갤러리별 실시간 화제/떡밥, 게임/이슈 여론, 특정 키워드 심층 검색까지 디시 유저들의 가감 없는 날것의 반응과 실제 댓글을 수집하고 분석합니다.

## 엄격 원칙 (Ground Rules)

1. **순수 디시인사이드 단독 조사**: 타 커뮤니티나 블로그 글을 절대 섞지 않습니다. 디시 내 검색 결과가 없을 경우 외부 검색으로 우회하지 않고 **"디시인사이드 내 언급 없음"**으로 즉시 결론짓고 조사를 종료합니다.
2. **OpenCLI 어댑터 최우선 사용**: `opencli dcinside list <galleryId>` 및 `opencli dcinside read "<postUrl>"`을 기본 수집 도구로 사용합니다.
3. **개념글 우선 탐색 원칙 (모드 B)**: 일반 토픽 및 이슈 브리핑 시 유저들의 검증과 추천을 받은 개념글(`--recommend`)을 1차 우선 탐색하고, 데이터가 부족할 때(3건 미만) 일반 글을 보조로 수집합니다.
4. **가감 없는 날것의 여론 보존**: 디시 특유의 비판적 시각, 솔직한 반응, 현실적인 여론을 누락 없이 반영하되 원색적인 욕설은 자연스럽게 순화합니다.
5. **대표 댓글 인용 필수**: 보고서에 디시 유저들의 실제 댓글 3~5개(Real Voice)를 인용(욕설 순화)하여 생생한 현장감을 제공합니다.

### 동적 타겟 갤러리 식별 및 마이너 갤러리 판별
내장 맵에 없거나 특정 게임/인물/이슈 갤러리를 찾아야 할 때는 DC 통합검색을 활용합니다:
```bash
curl -s "https://search.dcinside.com/combine/q/<키워드>" | grep -o 'https://gall.dcinside.com/[^"]*' | head -n 10
```
- **마이너 갤러리 자동 판별 규칙**:
  - 검색 결과 링크에 `/mgallery/` 경로가 포함된 경우(예: `https://gall.dcinside.com/mgallery/board/view/?id=<galleryId>...`) -> **마이너 갤러리**이므로 `opencli dcinside list` 실행 시 반드시 `--mgallery` 플래그를 추가합니다.
  - 검색 결과 링크가 `https://gall.dcinside.com/board/view/?id=<galleryId>...`인 경우 -> **일반 갤러리**이므로 별도 플래그 없이 호출합니다.

## 2. 표준 실행 워크플로우 (Step-by-Step)

### Step 1: 질의 유형 판별 및 모드 선택 (Intent Classification)
사용자의 요청 의도에 따라 모드를 선택하고 검색어를 준비합니다.

* **[모드 A: 제품/구매 분석]**:
  - 특정 제품명, 모델명, 가전, 전자기기 구매 고민("살까?", "후기 어때?"), 제품 간 스펙 비교.
  - 키워드 확장: 정밀 모델명(`52-N1000s`) -> 시리즈/패밀리명(`시리즈5`, `브라운 5`) -> 별칭/은어(`신갤주`, `구프로` 등).
* **[모드 B: 일반 토픽/이슈 브리핑]**:
  - 사건/사고, 게임 패치/메타, 커뮤니티 떡밥, 특정 인물/선수 여론, 단순 키워드 검색, 특정 갤러리 최신 동향.
  - 키워드 확장: 핵심 인명, 게임/패치 약칭, 사건 명칭 등 갤러리 내 실제 통용 단어.

### Step 2: 타겟 갤러리 식별 (Target Gallery Identification)
1. **1순위 (사용자 명시)**: 사용자가 특정 갤러리를 지정한 경우 해당 갤러리를 우선 사용 (예: "노트북갤에서 봐줘" -> `laptop` + `--mgallery`).
2. **2순위 (내장 맵 매핑)**: 제품군/카테고리가 내장 갤러리 맵에 있는 경우 해당 `galleryId` 사용.
3. **3순위 (cURL 동적 식별)**: 위 두 경우에 해당하지 않을 시 cURL 통합검색으로 갤러리 ID 및 마이너 갤러리 여부(`/mgallery/`) 식별.

### Step 3: 글 목록 수집 (Post Listing)
선택된 모드에 따라 최적화된 수집 명령을 실행합니다:

#### [모드 A 실행 명령 (키워드 검색)]
```bash
# 일반 갤러리
opencli dcinside list <galleryId> --search "<키워드>" --limit 20 -f yaml

# 마이너 갤러리 (--mgallery 추가)
opencli dcinside list <galleryId> --search "<키워드>" --mgallery --limit 20 -f yaml
```
* 검색 결과가 0건이면 검색어를 더 넓은 상위 단어(시리즈명, 브랜드명 등)로 완화하여 1회 재시도합니다.

#### [모드 B 실행 명령 (개념글 우선 탐색)]
화제성과 신뢰도가 높은 글을 우선 파악하기 위해 **개념글(`--recommend`) 1차 탐색**을 기본으로 적용합니다:
```bash
# 1차 시도: 개념글 우선 탐색
opencli dcinside list <galleryId> --search "<키워드>" [--mgallery] --recommend --limit 20 -f yaml
```
* **결과 판정 및 일반 글 보조 수집**:
  - 개념글 검색 결과가 **3건 이상**인 경우: 개념글 데이터를 메인으로 활용합니다.
  - 개념글 검색 결과가 **3건 미만**인 경우: `--recommend`를 뺀 일반 검색 목록을 추가 수집하여 보조 데이터로 확보합니다:
    ```bash
    opencli dcinside list <galleryId> --search "<키워드>" [--mgallery] --limit 20 -f yaml
    ```

#### 공통 종료 판정
검색어 완화 및 보조 수집 후에도 결과가 전혀 없으면 외부 검색(구글, 타 커뮤니티)으로 절대 우회하지 않고 즉시 **"디시인사이드 내 언급 없음"**으로 결론짓고 조사를 종료합니다.

### Step 4: 핵심 게시글 선별 및 상세 본문/댓글 수집
수집된 글 목록 중 조회수, 추천수(개추), 댓글 수가 활발한 글 **3~5개**를 선별하여 상세 내용을 읽습니다:
```bash
opencli dcinside read "<postUrl>" --comment-limit 20 -f yaml
```
* **주의**: `opencli dcinside read`에는 반드시 전체 URL(`https://gall.dcinside.com/...`)을 전달해야 합니다.
* 본문 요약뿐만 아니라 **댓글/대댓글에서 교차 검증되는 실사용자들의 진짜 반응과 대표 댓글**을 중점적으로 추출합니다.

### Step 5: 디시 특화 뉘앙스 해석 및 정제
* **바이럴 및 단순 칭찬 필터링**: 출처가 불분명한 무조건적 찬양 글은 배제하고, 고장 사례·실사용 불만·단점 질문·장기 사용기 중심으로 가중치를 둡니다.
* **디시 은어 및 반응 지표 해석**:
  * `개추 / 비추`: 강력 추천, 공감 / 비권장, 반대, 지뢰 판정
  * `침수엔딩 / 급사 / 벽돌`: 침수 고장, 급작스러운 기기 고장, 먹통
  * `돈지랄 / 계륵`: 가격 대비 효용 부족, 포지션이 애매함
  * `졸업템 / 종결`: 더 이상 상위 기변이 필요 없는 완성형 제품/세팅
  * `갤주 / 신갤주`: 해당 갤러리에서 압도적으로 추천받는 공식 대표 모델 또는 상징적 인물
  * `떡밥 / 불타다`: 갤러리 내 급상승 화제거리, 논쟁 과열
  * `분탕 / 어그로`: 의도적 갈등 유발 글 (전체 여론 왜곡 방지를 위해 필터링)

## 3. 최종 출력 보고서 포맷 (Output Templates)

조사 완료 후 사용자의 질문 모드(모드 A 또는 모드 B)에 맞는 템플릿을 선택하여 출력합니다.

### [모드 A 포맷: 제품/구매 분석]
```markdown

> 💡 **디시 갤러리 민심 한 줄 요약**: "한 줄 핵심 총평"  
> *(조사 갤러리: [갤러리명](URL), 분석 글 N개 / 댓글 M개 기준)*

---

### 1. 주요 장점 & 개추(추천) 포인트 👍
* **[핵심 장점 1]**: 실사용자가 체감하는 가성비, 성능, 사용 편의성
* **[핵심 장점 2]**: 동급/하위 모델 대비 우위 요소

### 2. 주요 단점 & 비추(지뢰) 포인트 ⚠️
* **[주의점/불만 1]**: 고장 빈도, 내구성 이슈, 사용 시 불편한 점
* **[주의점/불만 2]**: 상위 라인업 대비 아쉬운 한계점

### 3. 갤러리 내 경쟁 모델 & 대체재 비교 ⚖️
* **vs [경쟁 모델 A]**: 갤러리 유저들의 선택 기준 및 호불호
* **vs [경쟁 모델 B]**: 가격대별 추천 갈림길

### 4. 생생한 디시 댓글 한줄평 (Real Voice) 💬
* *"실제 유저 댓글 인용 1 (욕설 순화)"* — [게시글 제목](URL)
* *"실제 유저 댓글 인용 2 (욕설 순화)"* — [게시글 제목](URL)
* *"실제 유저 댓글 인용 3 (욕설 순화)"* — [게시글 제목](URL)
```
