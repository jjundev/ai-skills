# HyperFrames Plugin

This directory is the portable plugin package for HyperFrames by HeyGen in the [`jjundev/ai-skills`](https://github.com/jjundev/ai-skills) repository.

## Overview
HyperFrames enables AI agents (Claude Code, Antigravity, Codex) to author, preview, and render videos from HTML, CSS, and JavaScript.

## Included Skills
- `hyperframes`: Entry point — render contract, work loop, and per-genre guidance (launch films, explainers, captions, overlays, ...)
- `hyperframes-cli`: CLI by job — scaffold, check, preview, render, publish
- `hyperframes-registry`: Ready-made blocks and components (transitions, overlays, titles, charts, ...)
- `media-use`: Music, SFX, images, voiceover, transcripts, cutouts, colour grades, audio mixing
- `figma`: Figma design asset extraction and motion reconstruction
- `slideshow`: Live-presented decks with presenter mode
- `remotion-to-hyperframes`: Port Remotion / Lottie / Three.js / other video code into HyperFrames
